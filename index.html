Quem sou

Sou desenvolvedor indie focado em game design: sistemas, mecânicas e experiências que fazem sentido para quem joga. Uso Unity e Godot para tirar as ideias do papel.

No lado técnico, uso Python para análise de dados e automação e JavaScript para ferramentas web. Gosto de cruzar as duas áreas: dados que informam o design, e design que torna os dados compreensíveis.

Acredito que bons jogos nascem de iteração constante, de ouvir o feedback e de testar sempre.
